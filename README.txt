КАК ОТКРЫТЬ В INTELLIJ IDEA
1. Распакуй архив.
2. File -> Open -> выбери папку AlishevCourse -> OK.
3. Если сверху появится жёлтая плашка "Project JDK is not defined":
   нажми Setup JDK и выбери любую установленную Java (17 и новее) или Download JDK.
4. Открой любой файл из src, например Lesson01_HelloWorld.java.
5. Нажми зелёный треугольник слева от строки "public static void main" -> Run.

Запасной вариант: создай новый проект (File -> New -> Project -> Java),
скопируй все .java файлы из папки src в папку src своего проекта.

Уроки 7 и 8 просят ввод с клавиатуры: кликни в окно Run внизу и печатай там.
Каждый файл запускается отдельно и независимо от остальных.
